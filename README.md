# Miqayel

Մինիմալ Unreal Engine 5 C++ voxel-world նախագիծ։

Եթե Unreal Engine չունեք, կարող եք անմիջապես խաղալ `index.html` ֆայլը. կրկնակի սեղմեք դրա վրա և բացեք բրաուզերում։

## Գործարկում

1. Տեղադրեք Unreal Engine 5.4 կամ ավելի նոր տարբերակ։
2. Աջ քլիք արեք `Miqayel.uproject` ֆայլի վրա և ընտրեք **Generate Visual Studio project files**։
3. Բացեք `.sln` ֆայլը Visual Studio-ում և կառուցեք `Development Editor` կոնֆիգուրացիան։
4. Unreal Editor-ում տեղադրեք `VoxelWorld` actor-ը մակարդակի մեջ և սեղմեք **Play**։

Խաղացողը շարժվում է `WASD`-ով, իսկ տեսախցիկը՝ մկնիկով։ `VoxelWorld`-ը օգտագործում է Unreal-ի ներկառուցված Cube mesh-ը և ստեղծում է պարզ բլոկային հարթակ։
